# EduLead – Admission Lead Management System

EduLead is a full-stack Admission Lead Management System developed as an MVP for managing student admission enquiries from initial registration through counsellor assignment, follow-ups, status updates, and conversion.

The system provides separate dashboards and workflows for Admins, Counsellors, and Students/Leads.

---

## 📌 Project Overview

Educational institutions receive admission enquiries through multiple channels such as:

- Website
- Walk-ins
- Phone calls
- WhatsApp
- Education fairs
- Campaigns
- Other sources

Managing these leads manually can make it difficult to track follow-ups, assignments, lead status, and conversions.

EduLead provides a centralized system to manage the admission lead lifecycle.

### Lead Lifecycle
